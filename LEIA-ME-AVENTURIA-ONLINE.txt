AVENTURIA ONLINE — SERVIDOR GLOBAL (UM MUNDO SÓ)

Todo mundo que abrir o mesmo endereço entra no mesmo mapa, vê os outros
jogadores, conversa no chat e luta as mesmas raids.

------------------------------------------------
JOGAR NESTE COMPUTADOR
1. Instale Node.js 18 ou mais novo: https://nodejs.org
2. Nesta pasta, execute:  node server.js
3. Abra http://localhost:3000
4. NÃO abra o HTML direto (file://) — isso não conecta.

JOGAR NA MESMA CASA / WI-FI
- No terminal aparece um endereço tipo http://192.168.x.x:3000
- Celulares e PCs da mesma rede usam ESSE link.
- Se não abrir, libere a porta 3000 no firewall do Windows.

JOGAR PELA INTERNET (amigos em qualquer lugar)
Publique ESTE servidor uma única vez. Enquanto o processo estiver no ar,
existe só um mundo.

Opção rápida (Render, grátis):
1. Suba esta pasta para um repositório Git.
2. Em https://render.com crie um Web Service a partir do repo.
3. Build: npm install    Start: node server.js
4. Compartilhe o link HTTPS que o Render gerar (exemplo: https://aventuria-online.onrender.com)

Railway, Fly.io ou qualquer VPS também servem. O jogo e o WebSocket
usam o MESMO endereço — não precisa de porta extra.

IMPORTANTE
- Um processo = um mundo. Dois "node server.js" = dois mundos separados.
- O plano grátis do Render dorme após inatividade; o primeiro acesso
  pode demorar ~1 minuto para acordar.
- Chat: botão 💬. PvP: botão 🗡 (os dois precisam estar com PvP ligado
  e fora da Área Safe).
